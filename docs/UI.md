# 控制面板与快捷键

`MhwSrPanel.exe` 是本项目的独立 Windows 控制窗口。默认在从 Steam 启动游戏后收起到托盘，在游戏前台按 **End** 显示或隐藏。也可以双击游戏目录中的程序，或双击托盘中的 MHW SR 图标打开。

这是当前输入采集版本的界面：显示游戏与独立入口是否连接，以及实际的“DLSS 超分辨率尚未接通”状态。质量、平衡、性能、超高性能档位暂时禁用；界面本身不启用 DLAA、帧生成或 SR，也不改变渲染分辨率。

## 修改快捷键

1. 打开面板，点击“显示 / 隐藏面板”下的输入框。
2. 按下新的按键或组合键，例如 Insert、F10、Ctrl+Shift+D。
3. 点击“保存”，新快捷键立即生效，并保存到程序旁的 `MhwSrPanel.ini`。

可用 End、Home、Insert 等导航键和功能键，普通字母需配合 Ctrl 或 Alt。F8 保留给原生采集，F12 与 Esc 不接受为显示快捷键。编辑快捷键时暂停当前绑定，避免录入过程中关闭窗口。按住按键不会连续切换。

如果组合键已被其他应用占用，面板会提示并保留原绑定。写入配置失败同样保留原绑定。点击“恢复 End”可恢复默认键。快捷键只在本游戏或控制面板处于前台时注册，切换到其他应用后释放；游戏自身使用原始键盘输入时仍可能同时响应，请选未分配给游戏操作的组合。

“随游戏启动时隐藏面板”与快捷键一起保存。关闭按钮和 Esc（未编辑快捷键时）会收起到托盘；“退出面板”只关闭界面，不结束游戏，也不停止已经触发的采集。随游戏自动打开的面板会在该游戏进程退出后自动结束；手动打开的面板可留在桌面上修改配置。

## 显示范围与状态

本版适用于窗口和无边框模式，是单独的控制窗口，没有注入 D3D12 绘制层。它显示时可以获得鼠标焦点；切换到其他应用后取消置顶。真正的独占全屏可能切回桌面，尚未实现游戏内绘制菜单。

“独立入口已连接”仅表示当前游戏的控制接口存在，不表示 SR 已启用，也不表示当前正在采集。没有运行游戏时仍可打开面板改键。当前采集仍通过游戏内 F8 或已有控制脚本触发。

面板只保存自己的 UI 配置。它通过同目录游戏的进程路径和当前进程的原生控制事件判断连接，不加载渲染 DLL、不读写游戏内存、不发送采集命令，也不修改 `MhwNativeHost.ini`。启动器可在没有面板文件时继续原启动流程。

## 构建与安装

```powershell
cmake --build build --config Release --target MhwSrPanel MhwSrLauncher --parallel 2
```

面板仅使用 Windows API，没有新增第三方 UI 库。热键实现依据 Windows 的 [RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) 和原生 Hot Key 控件接口。

UI 更新包的清单类型为 `standalone-control-panel-v1`，只包含 `MhwSrLauncher.exe`、`MhwSrPanel.exe`、`MhwSrPanel.ini`。现有安装脚本支持备份与恢复这三个文件，不改原生采集 DLL、采集开关或方法校准。打包已有设置时应保留用户的 `MhwSrPanel.ini`。安装前需正常退出游戏和面板。

当前实现已通过编译与静态检查，尚待游戏内确认交互与快捷键行为；未运行自动化测试。
